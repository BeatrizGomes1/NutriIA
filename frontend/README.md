# Frontend

Espaço reservado para a aplicação cliente Android do NutriIA.

A stack planejada é Kotlin com Jetpack Compose. A estrutura do aplicativo e
suas telas serão definidas em uma etapa posterior.

Os requisitos contemplam autenticação, onboarding, perfil, Home, scanner,
resultado da análise, histórico, restrições e configurações.

O backend não deve depender diretamente de arquivos ou módulos desta pasta.
