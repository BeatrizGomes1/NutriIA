# v0004 — Versionamento de prompts

**Status:** reconstruído a partir da conversa.

## Objetivo

Criar um registro permanente dos prompts que orientam decisões e
implementações importantes, tornando o histórico compreensível para agentes
de IA e colaboradores.

## Prompt reconstruído

Criar uma pasta organizada para versionar prompts. Deixar claro que toda
implementação ou decisão importante deve gerar uma nova versão e registrar os
prompts mais recentes já utilizados.
